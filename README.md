# 👾 디지마인드 (DigiMind) - 은둔고립청년을 위한 루틴 & 온기 쉼터

일상의 작은 걸음(Small Wins)을 통해 건강한 습관을 만들고, 성취감 게이지를 채워 나만의 디지몬 아바타를 진화시키며, 온기 가득한 커뮤니티에서 응원과 소통을 주고받는 웹 애플리케이션입니다.

---

## 🚀 비주얼 스튜디오(VS Code)에서 실행하는 방법

### 1. 로컬 실행하기
1. Visual Studio Code에서 프로젝트 폴더 (`졸업작품`)를 엽니다.
2. 터미널(`Ctrl + ~`)을 엽니다.
3. 명령어 실행:
   ```bash
   npm start
   ```
4. 브라우저 접속:
   👉 **`http://localhost:3000`**

## 🌟 3대 핵심 기능

### 2. 🎮 나의 디지몬 & 퀘스트 탭

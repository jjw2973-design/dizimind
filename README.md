# 👾 디지마인드 (DigiMind) - 은둔고립청년을 위한 루틴 & 온기 쉼터

일상의 작은 걸음(Small Wins)을 통해 건강한 습관을 만들고, 성취감 게이지를 채워 나만의 디지몬 아바타를 진화시키며, 온기 가득한 커뮤니티에서 응원과 소통을 주고받고 포인트 보상을 받는 웹 애플리케이션입니다.

---

## 🚀 비주얼 스튜디오(VS Code)에서 실행하는 방법

### 1. 로컬 실행하기
1. Visual Studio Code에서 프로젝트 폴더 (`졸업작품`)를 엽니다.
2. 터미널(`Ctrl + ~`)을 엽니다.
3. 명령어 실행:
   ```bash
   npm start
   ```
4. 브라우저 접속:
   👉 **`http://localhost:3000`**

## 🌟 4대 핵심 기능

### 1. 🔑 로그인 / 동료들 탭
- 회원가입/로그인 및 접속 중인 은둔 동료 청년들의 디지몬 상태, 온기 온도(36.5℃) 실시간 구경

### 2. 🎮 나의 디지몬 & 퀘스트 탭
- 성취감 EXP 게이지 100% 진화 팝업 모달 + 진화 축하 **`+500 P`** 적립!
- 단계별(1단계/2단계/3단계) 퀘스트 완수 시 **`+50 P`** 지갑 적립!
- 나만의 커스텀 퀘스트 추가 기능

### 3. 💬 안심 온기 커뮤니티 탭
- 익명 응원 소통 (❤️따뜻해요 / 👏응원해요 / 👋인사해요) ➔ 응원 수신 시 **`+20 P`** & **`온기 온도 +0.2℃`** 상승!
- 비속어/유해어 클린 키워드 자동 정화 + 🚨 1:1 비밀 제보센터 & 24시간 위기 핫라인(109) 연계

### 4. 🎁 온기 포인트 / 현금 환전 상점 탭
- **내 온기 지갑 (My Wallet)**: 적립된 포인트 현황 및 내역
- **🛍️ 포인트 보상 상점 (기프티콘)**: CU/GS25 편의점 3,000원/5,000원권, 컴포즈 커피, 배달의민족 상품권 교환
- **💵 계좌 현금 환전 신청**: `10,000 P` 이상 적립 시 본인 은행 계좌로 현금 입금 신청!
